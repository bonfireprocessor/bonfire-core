# Agent Language Policy

## Speaking Language Restriction

This agent MUST respond exclusively in **German** or **English**. Responses in any other languages (e.g., French, Spanish, Chinese, Japanese, etc.) are strictly prohibited.

### Documentation and Code Language Rules

- **README files**: MUST be written in English only
- **Source code**: All comments, docstrings, and variable names MUST use English terminology
- **Code comments**: Never write technical documentation or comments in German - use English
- **Error messages**: Use English for all error handling and user-facing text
- **Configuration files**: Comments should be in English

> Exception: Conversational responses may be in German (or English), following the Speaking Language Restriction above.

## Coding Task Protocol

### Prioritizing Copilot Instructions

When performing coding tasks, this agent MUST also consult and follow the guidelines documented in `.github/copilot-instructions.md`. This file contains project-specific coding standards, conventions, and technical requirements that take precedence over general language policies for:

- Code style and formatting
- Architecture patterns and design decisions
- Testing strategies and coverage requirements
- Security best practices
- Project-specific APIs and interfaces

### Conflict Resolution

If `.github/copilot-instructions.md` contains conflicting directives with this file's policies:
1. Technical coding standards in Copilot instructions take precedence
2. Language for conversational responses follows this file (German/English only)
3. README files and code comments should still follow the language rules of this file

### Integration Example

When receiving a coding task:
1. **Step 1:** Review `.github/copilot-instructions.md` for relevant guidelines
2. **Step 2:** Apply project-specific conventions documented there
3. **Step 3:** Write code comments and documentation in English (per this file)
4. **Step 4:** Communicate with the user in German or English (per Speaking Language Restriction)

### Examples of Correct Usage

✅ Correct:
- README.md written in English
- Comment in code: `# Calculate checksum for payload`
- Error message: `"Invalid input parameter provided"`
- User response in conversation: German or English (whichever the user prefers)

❌ Incorrect:
- README.md with German documentation
- Code comment: `# Berechne Prüfsumme für die Payload`
- Error message: `"Ungültiger Eingabeparameter"`

### Implementation Notes

- When users communicate in German → respond in German
- When users communicate in English → respond in English  
- When users communicate in another language → politely request communication in German or English, then respond in one of those two languages
- Never auto-translate responses to other languages
- Never mix multiple languages within a single response

### Rationale

This policy ensures clear and consistent communication with the user, who has specified a preference for these two languages. It also helps maintain clarity and avoid potential misunderstandings that could arise from using unapproved languages.
